## poweradmin groups zones add

Add a zone to a group

### Synopsis

Associate a zone with a Poweradmin group.

```
poweradmin groups zones add [flags]
```

### Options

```

  -h, --help              help for add
      --zone-id string    Zone ID to add (required)
```
