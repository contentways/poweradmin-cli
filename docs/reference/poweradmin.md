## poweradmin

CLI for managing Poweradmin DNS

### Synopsis

poweradmin is a command-line tool for managing DNS zones and records via the Poweradmin REST API.

### Options

```
  -k, --api-key string   Poweradmin API key (overrides config and env)
  -h, --help             help for poweradmin
  -u, --url string       Poweradmin URL (e.g. https://dns.example.com)
  -v, --verbose          Log HTTP requests/responses to stderr for debugging
```
